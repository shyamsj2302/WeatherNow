# WeatherNow 🌦️

### Real-Time Weather Forecasting App with Voice Accessibility

A modern and fully responsive weather forecasting web application that provides **accurate real-time weather updates** with **speech-enabled accessibility features** for visually impaired users. Built using **HTML5, CSS3, JavaScript**, and the **OpenWeatherMap REST API**, the application delivers a seamless and inclusive user experience across desktop, tablet, and mobile devices.

---

## 🚀 Features

* 🌍 Real-time weather forecasting for any city/location
* 🎙️ **Voice-enabled weather search using Speech Recognition API**
* 🔊 **Text-to-Speech weather output for visually impaired users**
* 🌡️ Temperature unit toggle (Celsius ↔ Fahrenheit)
* 🔎 Dynamic city/location search functionality
* 📱 Fully responsive and mobile-friendly UI
* ☁️ Live weather details including:

  * Temperature
  * Humidity
  * Wind Speed
  * Weather Conditions
  * Feels Like Temperature
* 🎨 Clean and modern user interface
* ⚡ Fast asynchronous API integration for instant weather updates
* ♿ Accessibility-focused design for inclusive usability

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **API:** OpenWeatherMap REST API
* **Accessibility:** Web Speech API (Speech Recognition & Speech Synthesis)

## 🔑 API Integration

This project uses the official OpenWeatherMap API to fetch real-time weather information.

### Setup Instructions:

1. Create an account on
   [OpenWeatherMap](https://openweathermap.org/api?utm_source=chatgpt.com)
2. Generate your API key
3. Replace the API key inside `script.js`

```javascript
const API_KEY = "YOUR_API_KEY";
```

## 🎤 Accessibility Features

### Speech Input

Users can search weather forecasts using voice commands through the browser’s Speech Recognition API.

Example:

> “Show weather in London”

### Speech Output

The application reads weather information aloud using Text-to-Speech functionality, making the app accessible for visually impaired users.

Example Output:

> “The current temperature in London is 24 degrees Celsius with scattered clouds.”
